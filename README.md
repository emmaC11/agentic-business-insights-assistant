# Agentic-Business-Insights-Assistant - DBS Final Project
Small businesses that use Square as their point-of-sale platform generate rich sales data from their daily operations. However, this data is only raw transaction data, it shows what has already happened in the business and requires the owner to understand how to leverage the reports square provides. My project has built an agentic-business-insights assistant that is predictive & conversational. Sales data is ingested via the Square API, PII data is removed at ingestion time, no sensitive data is stored in the system. This data is aggregated into a weekly item-level series. My EDA of this series highlighted extreme sparsity over the 58-week period of production data fetched. Most item-week observations are 0. I decided to opt for a tiered architecture approach, classifying items into a “rare”, “intermittent” and “regular” tier and applying forecasting models and evaluation metric to specific tiers. Four models were tested per item across 1017 model-item combinations, with a “winner” selected for each item. The forecasts and data query tools are callable via a custom-built Model Context Protocol (MCP) server that is callable via any compatible agent.
